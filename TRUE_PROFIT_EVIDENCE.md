# Fence true-profit evidence

Canonical formula (all revenue/costs are ex GST):

- GP = revenue/subtotal - internal material/removal cost - internal labour
- Commission = 15% of GP when GP is positive, otherwise $0
- True GP kept = GP - commission
- Floor warning is advisory/non-blocking when true GP kept is below 25% of revenue

Worked example:

| Field | Value |
| --- | ---: |
| Revenue ex GST / subtotal | $2,700.00 |
| Internal material/removal cost | $1,231.00 |
| Internal labour | $700.00 |
| GP before commission | $769.00 |
| Commission (15% of positive GP) | $115.35 |
| True GP kept | $653.65 |
| True GP kept % | 24.2% |
| Floor warning below 25% | true |
